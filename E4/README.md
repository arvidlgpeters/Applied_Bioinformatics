# E4 — Gene Prediction in *Saccharomyces cerevisiae* using Hidden Markov Models

This analysis implements and trains a two-state (coding / non-coding) Hidden Markov Model in R to predict gene locations directly from genomic DNA sequence, without relying on existing gene annotations. Model performance is evaluated against reference annotations produced by [Augustus](https://bioinf.uni-greifswald.de/augustus/)


1. **Model setup** — initializes an HMM with two hidden states (`C` = coding, `N` = non-coding) over the four-letter DNA alphabet, using base-composition-informed initial transition and emission probabilities.
2. **Training** — trains the model using Viterbi training on chromosomes 6 and 7 of the yeast reference genome.
3. **Prediction** — applies the Viterbi algorithm to hold-out chromosomes to decode the most likely state sequence (coding vs. non-coding) along the genome.
4. **Translation** — converts predicted coding regions into amino acid sequences.
5. **Evaluation** — compares the distribution of predicted protein lengths against Augustus reference annotations, both before and after training, to assess whether training improves prediction quality.
6. **Second model** — repeats the process with a differently parameterized HMM (`max_model`) on a different chromosome split, as a comparison.

## Dependencies

- R (≥ 4.0 recommended)

- [`Biostrings`](https://bioconductor.org/packages/Biostrings/) (Bioconductor)
- [`tidyverse`](https://www.tidyverse.org/)
- [`purrr`](https://purrr.tidyverse.org/)

The `.Rmd` setup chunk will attempt to install any missing packages automatically (via CRAN or `BiocManager` for Bioconductor packages).

## Note on reproducibility

The script currently uses `setwd()` with a hardcoded path to set the working directory. To run it locally, either:
- edit the `setwd()` calls to point to wherever you've placed this folder, or
- open the `.Rmd` in RStudio as part of an RStudio Project rooted at this repo, and replace `setwd()` with a portable path helper such as `here::here()`.
